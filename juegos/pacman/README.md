# PAC-PLANETS

`index.html` es la versión de un solo archivo del juego (copia de `PAC-PLANETS-standalone.html` del proyecto pac-planets). El sitio la carga en la sección Juega.

Para actualizarla: en el proyecto del juego ejecuta `npm run build:single` y copia `dist-single/index.html` aquí.

`THIRD-PARTY-NOTICES.txt` contiene los avisos de licencia de three.js y Vite, que van incluidos en el juego. Debe quedarse en esta carpeta al reemplazar `index.html`; si el juego cambia de versión de esas bibliotecas, actualiza ahí los números de versión.
